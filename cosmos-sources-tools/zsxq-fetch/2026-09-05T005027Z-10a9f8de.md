## Why the change was needed

Image acquisition failures exposed only the backup script error, without establishing the outcomes of the preferred browser methods. The ordered procedure needs per-image evidence before entering a fallback, including for images inside linked webpages.

## Reproduction

Review an image failure handoff that contains only a script HTTP or content-type error. It does not establish whether browser resource export or browser download was attempted. Prior diagnostic browser exports succeeded for sampled images, but the exact earlier browser sequence could not be reconstructed.

- `.codex-plugin/plugin.json`: bump the patch version from 0.20.5 to 0.20.6.

## Diff

- After: each fallback has an explicit per-image prerequisite, preceding outcomes survive a final script failure, and linked-page images follow the same acquisition sequence while their page is open.
