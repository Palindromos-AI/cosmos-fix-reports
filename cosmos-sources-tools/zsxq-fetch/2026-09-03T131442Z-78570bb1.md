## Why the change was needed

Live Knowledge Planet file cards omitted the `data-file-id` attribute that the active browser contract required, so valid PDF, HTML, and Word attachments failed before the official download flow. The collector should accept the real card shape and still refuse ambiguous candidates.

## Reproduction

1. Open a signed-in Knowledge Planet timeline or topic detail page containing a supported file attachment.
2. Inventory the target topic with browser contract v10.
3. Observe that the supported file card has an exact filename but no `data-file-id`, causing attachment validation to fail.
