## Why this change was needed

The marketplace did not provide a workflow for turning conversation-derived rules and workflows into a durable, user-reviewed methodology library. The expected behavior is an explicit-invocation assistant that lists the existing library on every run, lets the user choose between updating an existing methodology and creating a new one, drafts changes for review, and persists only after unambiguous confirmation.

## Reproduction

1. Inspect the marketplace catalog and observe that no methodology-management plugin is available.
2. Attempt to invoke `$methodology-assistant` and observe that the skill is absent.
